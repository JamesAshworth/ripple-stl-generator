# ripple-stl-generator

Small TypeScript app to generate a 3D-printable STL of a cylindrical box whose top surface is a rippled water pattern, formed by interference between multiple point wave sources.

Initial concept generated by Claude AI.

## Getting started

Clone the repository, then:

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173/`). To produce a production build instead, run `npm run build` (output in `dist/`).

## Using the generator

The model is a solid cylinder: flat bottom and sides, rippled top. Ripples are the sum of circular waves radiating from each source, so overlapping sources create interference patterns.

Every control is a paired slider and number box — drag the slider for coarse changes or type an exact value in the box. Tab moves between the number boxes.

### Ripple sources

Each source is a point the waves radiate from. Use **Add Source** to add one and the bin icon to remove one (at least one source must remain). Per source:

| Control | Meaning |
|---------|---------|
| X / Y | Position of the source in mm, relative to the centre of the surface. Sources can sit outside the circle — waves still propagate in. |
| Power | Relative wave height for this source, scaled by the global amplitude. |
| Frequency | How tightly packed this source's wave rings are. Higher = more, narrower rings. |

Mixing sources with different frequencies and powers produces more organic, less symmetrical patterns.

### Global settings

| Control | Meaning |
|---------|---------|
| Surface Size | Diameter of the cylinder in mm. |
| Box Thickness | Depth of solid material below the rippled surface. Increase for strength. |
| Resolution | Grid density of the mesh. Higher = smoother surface but a larger STL file and slower generation. |
| Wave Amplitude | Overall wave height in mm, multiplied by each source's power. |
| Number of Wave Rings | How many phase-offset wave trains each source emits. More rings soften and layer the pattern. |

### Generating the STL

Click **Generate & Download STL** to build the mesh and download `rippling_water.stl` (binary STL). Generation happens entirely in the browser; at high resolution it may take a moment.

## Printing tips

- Print flat side down — no supports needed.
- Keep wave amplitude modest relative to box thickness so troughs don't cut through the base.
- Higher resolution helps mostly at larger surface sizes; 100 × 100 is plenty for a 200mm disc.
